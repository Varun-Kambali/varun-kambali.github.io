# varun-kambali.github.io

> **Work in progress.** The site is being built on feature branches; see the open pull requests.

Portfolio site for Varun Kambali, AI Engineer (Bengaluru). It is an **evidence map**: every skill links to the resume lines and public projects that back it up, and a project board reads each project's status and headline eval result straight from its GitHub repo.

Static HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.
